🏪 Admin Katalog UFO Kebonsari

Masuk ke Panel Admin

Gunakan akun admin yang sudah dibuat di Firebase Authentication.

1. Format Excel

File Excel harus punya 4 sheet dengan nama persis: KATALOG, SETTING, BANNER, PROMO. Baris pertama tiap sheet adalah judul kolom (akan dilewati). Kalau belum punya filenya, unduh template di bawah supaya urutan kolomnya pasti benar.

Sheet KATALOG (kolom A–O)
A BrandB Tipe
C HargaD Kategori
E SubKategoriF–J Spek1–Spek5
K Foto (nama file saja)L Status (BARU/PROMO/BESTSELLER)
M Unggulan (YA/kosong)N Urutan (angka)
O Banner (opsional)

2. Upload Excel

Produk (KATALOG): di-update berdasarkan Brand+Tipe — produk lama yang tidak ada di file ini tidak akan terhapus.
Setting: hanya key yang ada di sheet ini yang diperbarui.
Banner & Promo: seluruh isi lama diganti total dengan isi sheet ini (karena tidak ada kolom kunci unik seperti Brand+Tipe).
