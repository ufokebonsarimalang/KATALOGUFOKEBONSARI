🏪 Admin Katalog UFO Elektronik Malang

Masuk ke Panel Admin

Gunakan akun admin yang sudah dibuat di Firebase Authentication.

1. Format Excel

File Excel harus punya 4 sheet dengan nama persis: KATALOG, SETTING, BANNER, PROMO. Baris pertama tiap sheet adalah judul kolom (akan dilewati).

Sheet KATALOG (kolom A–O)
A BrandB Tipe
C HargaD Kategori
E SubKategoriF–J Spek1–Spek5
K Foto (nama file saja)L Status (BARU/PROMO/BESTSELLER)
M Unggulan (YA/kosong)N Urutan (angka)
O Banner (opsional)

Kategori valid: Elektronik, Gadget, Rumah Tangga.

2. Upload Excel (Full Sync)

🔄 Mode Full Sync Aktif: Setiap upload akan menghapus SEMUA produk lama di Firestore, lalu menggantinya total dengan isi Excel. Website akan persis sama dengan Excel — produk yang tidak ada di Excel otomatis terhapus dari website.
⚠️ Penting: Pastikan Excel sudah benar sebelum upload. Data lama tidak bisa dikembalikan setelah dihapus.

3. Hapus Semua Produk (Emergency)

Hapus total semua produk di Firestore tanpa upload Excel. Berguna kalau mau bersih-bersih darurat.
